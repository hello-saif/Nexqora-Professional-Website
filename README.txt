NEXQORA — PROFESSIONAL STATIC WEBSITE

Files:
- index.html       Main website
- styles.css       Responsive styling
- script.js        Navigation, scroll effects and reveal animations
- assets/          Nexqora logo files

Quick start:
1. Open index.html in a browser to preview locally.
2. Replace hello@nexqora.com with your real business email when ready.
3. Replace/add your real website, LinkedIn URL and social links when available.
4. Upload the complete folder to a static host such as GitHub Pages, Netlify, Vercel or your own hosting.

The site is responsive for desktop, tablet and mobile.
